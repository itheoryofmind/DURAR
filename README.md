# الدرر السنية في الأجوبة النجدية

موقع قراءة الكتاب وتحميله كاملاً.

- الموقع: https://itheoryofmind.github.io/DURAR/
- تحميل الكتاب كاملاً: https://itheoryofmind.github.io/DURAR/download/

## محتويات المستودع

- `vols/N.pdf`: صور صفحات كل جزء كما في المسح الأصلي (archive.org/details/1241825)، مرتبة بترقيم الطبعة. الجزء الثامن ص ٤١–١٢٠ كانت مقلوبة في المسح فرُتبت.
- `vols/N.txt`: القراءة الآلية المضمنة في المسح (للبحث في الصفحات التي لا نص مطابقاً لها).
- `data/tN.json`: نص كل صفحة من المكتبة الشاملة (الطبعة السادسة ١٤١٧هـ)، لا يُدرج نص صفحة إلا إذا طابق أولها وآخرها قراءة جديدة لصورتها من الجهتين.
- `data/fihris.json`: مواضع أرقام الصفحات في الفهارس المطبوعة لكل جزء، لجعلها تعمل باللمس.
- `data/heads.json`: عناوين الكتب والأبواب من فهرسة المكتبة الشاملة مع صفحة بدايتها.
- `book/`: ملف الكتاب الكامل مقسماً لقطع يجمعها صفحة التحميل ويتحقق من سلامتها.
