# اقرأني أولاً: نقل موقعَي «سيرته» و«الدرر السنية»

هذا الملف لمن يقوم بالموقعين بعد صاحبهما. فيه كل ما تحتاجه لتنقل الموقعين إلى حساباتك أنت، أو إلى دومين جديد إذا انتهت مدة الدومين الحالي. الخطوات كلها تُعمل من الجوال إلا ما نُبّه عليه.

## ما الذي يقوم عليه الموقعان؟

١) **GitHub**: فيه ملفات الموقعين كلها، والنصوص، والصور، والكتب المصوّرة (في «الإصدارات» Releases). وهو الذي ينشر الموقعين (GitHub Pages).
- موقع السيرة: المستودع `SIRA`
- موقع الدرر: المستودع `DURAR`

٢) **Cloudflare**: فيه الدومينان، والخادم الصغير الذي يشغّل لوحة التحكم والتنبيهات (`push.` قبل دومين السيرة)، والبريد (report@ و feedback@).

٣) **لوحة التحكم**: صفحة على الخادم، تدخلها بمفتاحك. فيها كل الإعدادات والقرارات، وتستطيع تنزيلها في ملف واحد واستعادتها.

## قبل أي شيء (يفعله صاحب الموقع وهو موجود)

- يجعلك «رئيسياً» في «المساعدون» في لوحة التحكم، فتعمل معه في الموقعين كما هما الآن.
- يُبقي حسابه في GitHub ولا يحذفه حتى تنتهي من النقل.
- **أسهل طريق للنقل كله**: أن ينقل صاحب الموقع ملكية المستودعين إلى حسابك في GitHub. فتنتقل الملفات والكتب المصوّرة والإعدادات كلها بضغطة، بلا تنزيل ولا رفع:
  GitHub ← المستودع ← Settings ← في آخر الصفحة Danger Zone ← **Transfer ownership** ← يكتب اسم حسابك. ويفعل ذلك للمستودعين `SIRA` و`DURAR`.

## إن لم يمكن نقل الملكية

من لوحة التحكم ← «النسخة الكاملة والنقل»:
- **ملفات الموقع كاملة (ZIP)** لكل موقع. وهو ملف كبير. رفعه إلى مستودع جديد يحتاج **حاسوباً** (برنامج GitHub Desktop أو `git`).
- **روابط الكتب المصوّرة**: ملف فيه رابط كل كتاب. نزّلها وارفعها في «الإصدارات» في مستودعك بالأسماء نفسها.
- **الإعدادات والقرارات**: ملف صغير، احفظه عندك.

سمِّ المستودعين بالاسمين نفسيهما: `SIRA` و`DURAR`.

## الخطوات على حساباتك

### ١) الدومين في Cloudflare
- أنشئ حساباً في Cloudflare، ثم Add a domain، واكتب دومين السيرة. ثم افعل مثله لدومين الدرر.
- غيّر «خوادم الأسماء» (Nameservers) عند الجهة التي سجّلت فيها الدومين إلى الخادمين اللذين يعطيك إياهما Cloudflare.
- في DNS لكل دومين أضف:
  - `CNAME` الاسم `@` القيمة `اسم-حسابك.github.io`
  - `CNAME` الاسم `www` القيمة `اسم-حسابك.github.io`
- اترك الوكيل (السحابة البرتقالية) **مطفأً** لهذين السجلين.

### ٢) تغيير الدومين واسم الحساب في الملفات (مرة واحدة)
في كل مستودع (`SIRA` ثم `DURAR`): Actions ← **نقل الدومين** ← Run workflow، واكتب:
- دومين السيرة الجديد، ودومين الدرر الجديد. إن لم يتغيّر الدومين فاتركه كما هو.
- اسم حسابك في GitHub.
- **بصمة المفتاح**: افتح ملف «الإعدادات والقرارات»، وابحث عن `"keys"`:
  - إن كان عندك مفتاح صاحب الموقع، فخذ الأرقام التي بعد `"owner"`.
  - وإن كنت «رئيسياً» بمفتاحك أنت، فخذ الأرقام التي بعد اسمك في `"boss"`.
  - انسخ الـ٦٤ حرفاً كما هي. بعدها يصير مفتاحك هو مفتاح صاحب الموقع في الموقع الجديد.

### ٣) نشر الموقعين (GitHub Pages)
في كل مستودع: Settings ← Pages ← Source: **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`. وفي Custom domain اكتب دومين ذلك الموقع، ثم فعّل **Enforce HTTPS** بعد دقائق.

### ٤) الخادم ولوحة التحكم
- في Cloudflare: My Profile ← API Tokens ← Create Token ← قالب **Edit Cloudflare Workers**، وأضف إليه صلاحية **Workers KV Storage: Edit** و**D1: Edit**، ثم أنشئه وانسخه.
- في المستودع `SIRA`: Settings ← Secrets and variables ← Actions ← New repository secret. الاسم `CLOUDFLARE_API_TOKEN` والقيمة هي ما نسخته.
- Actions ← **push-worker** ← Run workflow. انتظر حتى يصير أخضر.
- لوحة التحكم الآن على: `https://push.دومين-السيرة/o`. ادخلها بمفتاحك.
- في لوحة التحكم ← «النسخة الكاملة والنقل» ← **استعادة من نسخة سابقة**، واختر ملف «الإعدادات والقرارات». فتعود كل الإعدادات والقرارات كما كانت.
- **مفتاح GitHub للنشر الفوري**: في لوحة التحكم بطاقة تطلبه، وفيها شرحه. أنشئه من حسابك في GitHub.
- **المساعدون**: مفاتيحهم لا تنتقل. أضفهم من جديد.

### ٥) البريد
Cloudflare ← دومين السيرة ← Email ← Email Routing. أضف `report@` و`feedback@` وحوّلهما إلى بريدك.

## أشياء تنتبه لها

- لا تكتب مفتاحك في أي مكان عام، ولا في رابط تشاركه.
- إذا انتهت مدة الدومين ولم يُجدَّد، يتوقف الموقع حتى تربطه بدومين جديد بالخطوات أعلاه. والمحتوى كله باقٍ في GitHub.
- التنبيهات التي اشترك فيها القرّاء على الدومين القديم لا تنتقل. يشتركون من جديد في الموقع الجديد.
- كل نصوص الكتب في الموقعين منقولة من مصادرها بأمانة. لا تُعدَّل إلا من لوحة التحكم، وبعد التحقق من صورة المطبوع.
